# Turbofan Cycle Study: CFM56-7B26

Design-point cycle analysis, thrust calculation and component sizing of the CFM56-7B26 turbofan, completed as a four-week Propulsion Systems internship project.

Author: Eliudi Elphace Tonda.
Status: Week 1 complete (planning). Weeks 2 to 4 planned.

## Project aim

Using a station-by-station, one-dimensional design-point model, calculate the net thrust and thrust specific fuel consumption (TSFC) of the CFM56-7B26 at sea-level static takeoff (Mach 0, ISA). Estimate the fan, core and nozzle flow areas from the results, then compare thrust, TSFC and fan diameter with published certification and ICAO data.

## Scope summary

| Item | Choice |
|---|---|
| Engine | CFM56-7B26, two-spool, separate-flow, high-bypass turbofan |
| Design point | Sea-level static takeoff, Mach 0, ISA (ISO 2533) |
| Method | Station-by-station 1D model, SAE AS755 station numbering |
| Gas properties | Temperature-dependent (NASA CEA or Cantera), not a single constant gamma |
| Out of scope | Off-design maps, CFD, structural design, emissions, noise |
| Optional extension | Cruise design point (35,000 ft, Mach 0.78), only after takeoff validation |

## Validation approach

Published inputs (bypass ratio, overall pressure ratio, fan diameter) are fixed first. Turbine inlet temperature, which is not published, is tuned to match thrust. TSFC and fan diameter are then treated as independent checks.

| Quantity | Target | Role |
|---|---|---|
| Takeoff net thrust | Within 1 % after tuning (untuned error also reported) | Calibration |
| TSFC | Within 10 % of value derived from ICAO fuel flow | Independent check |
| Fan tip diameter | Within 5 % of published value | Independent check |

## How to run

Keep all the `.py` files in the same folder. `sweep.py` and `profile.py` import from `cycle.py` and `massflow.py`.

**1. Check the mass-flow estimate**

```
python massflow.py
```

Expected output:

```
Fan annulus area A = 1.7149 m^2  (D_tip=1.549 m, htr=0.30)
Fan-face static: T=268.8 K, P=79.44 kPa, rho=1.0297 kg/m^3, V=197.2 m/s
Preliminary mass flow estimate m0 = 348.2 kg/s
```

**2. Run the cycle model**

```
python cycle.py
```

Expected output:

```
CRUISE   M0.80/35,000ft T4=1300K: Fsp=153.67 N.s/kg  TSFC=0.5547 lb/(lbf.hr)
TAKE-OFF SLS/M0         T4=1615K: Fsp=335.86 N.s/kg  TSFC=0.3443 lb/(lbf.hr)
Thrust = 116948 N (published 116988 N)
```

**3. Reproduce Figure 1 (calibration sweep)**

```
python sweep.py
```

Prints a table of T4, thrust and TSFC from 1500 K to 1690 K (for example 116,620 N at 1610 K and 117,272 N at 1620 K), then saves `calib_sweep.png` next to the script.

**4. Reproduce Figure 2 (station profile)**

```
python profile.py
```

Prints the temperature and pressure at each station and saves `profile.png`.

**5. Verification (ideal cycle)**

```
python ideal_cycle.py
```

Expected: the hand check `Tt3 = Tt2 x OPR^0.2857` and the code value agree to 0.0000 K.

## Using the model in your own scripts

```python
from cycle import cycle, BASE
from mass_flow import m0

result = cycle((0.0, 0.0), T4=1615.0, **BASE)   # flight = (Mach, altitude in m)
print(result["Fsp"], result["TSFC_lb"], result["Tt3"])
print("Thrust (N):", result["Fsp"] * m0)
```

`cycle()` returns a dictionary with the total temperature and pressure at every station (`Tt2`, `Pt13`, `Tt25`, `Tt3`, `Tt4`, `Tt45`, `Tt5`, ...), the fuel-air ratio `f`, specific thrust `Fsp` (N.s/kg), `TSFC_lb` (lb/(lbf.hr)) and the nozzle states `core` and `byp` (Mach number, velocity, choked or not).

## Results

| Quantity | Calculated | Published reference | Difference |
|---|---|---|---|
| SLS take-off thrust | 116,948 N | 116,988 N | -0.03% |
| SLS take-off TSFC | 0.3443 lb/(lbf.hr) | 0.330 (CFM56 family, not -7B26-specific) | +4.33% |
| Cruise TSFC (M0.80, 35,000 ft, T4 = 1300 K) | 0.5547 lb/(lbf.hr) | about 0.545 | +1.78% |

Before calibration, the first-pass model with generic efficiencies under-predicted thrust by 5.47% (110,593 N). After refining the efficiencies and calibrating T4, it lands within 0.03%.

## Method in brief

Station numbering follows SAE AS755: 0 ambient, 2 fan face, 13 fan exit, 25 booster exit, 3 HPC exit, 4 burner exit, 45 HPT exit, 5 LPT exit, 9 core nozzle, 19 bypass nozzle.

- Total temperature and pressure ratios across each component, using isentropic efficiencies
- Fuel-air ratio from a burner energy balance
- HPT drives the HPC and LPT drives the fan and booster (power balance)
- Both nozzles checked for choking against the critical pressure ratio
- Specific thrust and TSFC from the momentum equation, with a pressure-thrust term for choked nozzles

---

## Assumptions and limitations

- **The mass flow (348.2 kg/s) is derived from the published fan diameter**, not from a published airflow figure. It is used only to turn specific thrust into newtons.
- **T4 = 1615 K is a calibrated value.** No published turbine entry temperature was found.
- **The take-off TSFC reference (0.330) is a family-wide figure**, not specific to the -7B26.
- The booster (three real stages) is modelled as one stage.
- Cooling air is treated simply: it is removed at the HPC exit and remixed after the HPT.
- Two-value gas model (cold and hot side constants), not fully variable properties.
- The three-significant-figure agreement of the thrust result is partly built in, because T4 was tuned to match the published thrust.

## Week 3 hand-off

Week 3 sizes the fan, core and nozzles from this model. One point needs care:

The Week 2 mass flow comes from the fan diameter, and T4 was then tuned to match thrust. If Week 3 computes a fan diameter from the same thrust, it will return the diameter that was put in, so that check would be circular. To make the Week 3 diameter comparison a real prediction, T4 should be calibrated on a quantity that does not depend on engine size (TSFC), and the mass flow then taken as `m0 = F_target / Fsp`. With T4 calibrated on TSFC = 0.330, the predicted fan diameter is about 1.573 m, which is 1.57% above the published 1.549 m.
